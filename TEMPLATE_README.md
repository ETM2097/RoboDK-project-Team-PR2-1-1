#Proposed Template Structure:

1. **Project Overview** - Brief description of the component/module (Just the general idea)
2. **Implementation Rationale** - Why the current approach was chosen
3. **Core Mechanics** - Detailed explanation of how the code works
4. **System Integration** - Communications with other station components (How does the robot you are programming comunicate with the rest of the station?)
5. **Alternative Approaches** - Methods considered and reasons for rejection (What have you descarted and why)
6. **Technical Specifications** - Key parameters, algorithms, and design decisions (Methods and variables used in the code)
7. **Testing & Validation** - Test results and performance report (how does the code and robot perform?)
8. Future Improvements - Identified optimizations and enhancements (What can be improved? Why will it be improved or why it wont?)
9. References & Documentation - Supporting materials and standards (Have you used any documentation? You can link the readme on the project if you just used it)
