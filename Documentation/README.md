# Documentation

## Purpose
This folder contains documentation for the RoboDK team project, including improvement notes, testing results, and team communication.

## Documents

### Project Documentation
- `PROJECT_OVERVIEW.md` - Complete project description and architecture
- `TEAM_RESPONSIBILITIES.md` - Roles and responsibilities for each team member
- `IMPROVEMENTS.md` - Log of improvements and changes made by team members

### Technical Documentation
- See `/Handshake/handshake_protocol.md` for communication protocol details
- See individual robot folder READMEs for specific robot programs

## Guidelines
1. Use clear, concise language
2. Include dates for all updates
3. Reference specific files or functions when documenting changes
4. Include any issues encountered and how they were resolved
